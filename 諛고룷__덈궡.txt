폴더 구성
- index.html  : 사이트 본문
- images/     : 대표작 캡처, 공유 미리보기 그림(og.jpg)
- media/      : 무역 업무 도구 9개의 실제 화면 녹화 영상(mp4)과 첫 장면 사진(jpg)

1. 이 폴더 "안의" index.html, images, media 를 GitHub 저장소에 그대로 올립니다.
   (저장소 첫 화면에 index.html 이 바로 보여야 합니다. 폴더 이름은 모두 소문자 그대로)
2. Vercel → Add New → Project → 저장소 Import → Deploy
3. 시크릿 창과 휴대폰으로 열어 영상이 재생되는지 확인합니다.

[채울 것]
- index.html 아래쪽 <script> 맨 위 PROFILE 에 email, phone
- 이력서: 파일 이름을 정확히 resume.pdf (모두 소문자, .pdf.pdf 가 되지 않게) 로 바꿔 index.html 바로 옆에 올리기
  · 휴대폰 번호·주소는 지우거나 가리기 (공개 사이트입니다)
  · 파일이 없으면 이력서 버튼이 '준비 중'으로 흐려지고, 누르면 안내 문구가 뜹니다 (오류 화면 대신)
  · 바로보기 HTML 파일에서는 이력서가 열리지 않습니다. 배포한 주소에서 확인하세요
- 프로필 사진은 images/profile.jpg
- 배포 후 <head> 의 og:image 를 https://내주소/images/og.jpg 처럼 전체 주소로
- 노란색 [ ] 빈칸: 만든 계기, BidLens 정확도, 지원 회사, 1분 자기소개 속 경험, 면접 Q10 답
- 5·6번 작품 주소(Aurelis 2개 — 로그인 화면이 뜨는 주소)를 공개 주소로
- 효과 계산 숫자는 (예상)·(가정)입니다. 직접 재 보면 바꾸세요.

[영상 바꾸기]
- media 폴더의 같은 이름 파일(예: tradechecker.mp4)을 새 녹화로 덮어쓰면 됩니다.
- 영상은 소리 없이 반복 재생됩니다. 휴대폰 '동작 줄이기' 설정이면 자동 재생 대신 재생 버튼이 나옵니다.

[작품 목록]

- 목표 개수를 바꾸려면 index.html 의 GOAL = 50 숫자만 바꾸세요.

  이 한 줄도 빼려면 index.html 의 SHOW_OTHER = true 를 false 로 바꾸세요.
- 새 무역 도구를 만들면 PROJECTS 목록에 추가하면 카드·필터·진행 막대가 자동으로 늘어납니다.
